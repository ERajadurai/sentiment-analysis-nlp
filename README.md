# Sentiment Analysis using NLP

## 📌 Project Overview

This project focuses on classifying product reviews into positive or negative sentiments using Natural Language Processing (NLP) techniques and machine learning models. It helps in understanding customer opinions automatically.

## 🎯 Objective

* Analyze product reviews
* Classify sentiment (Positive / Negative)
* Improve decision-making using data insights

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* NLP techniques (Text preprocessing, Tokenization, Stopword removal)
